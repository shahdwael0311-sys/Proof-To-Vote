# Proof-To-Vote

Proof-To-Vote is a blockchain-based electronic voting system developed as a graduation project for the Cybersecurity program at the Arab Academy for Science, Technology and Maritime Transport (AASTMT).

The project uses Solidity smart contracts and Ethereum blockchain technology to support transparent and verifiable voting, alongside a web application and SQL database.

**Technologies:** Solidity, Ethereum, Truffle, JavaScript, Python, FastAPI, MySQL, MetaMask.
